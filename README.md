# 세레스 요리 도감

마인크래프트풍 요리 도감 웹사이트입니다. 프레임워크 설치 없이 HTML/CSS/JS로 실행됩니다.

## 시작하기

1. `index.html`을 브라우저에서 열면 기본 예시 데이터가 표시됩니다. 로컬 파일로 열 때는 `recipes.json` 자동 읽기가 제한될 수 있습니다.
2. 우측 상단 **⚙ 관리**에서 요리를 추가/수정/삭제하고 배너, 제목, 색상을 변경할 수 있습니다.
3. 관리자 화면에서 **JSON 내보내기**로 `recipes.json`을 다운로드합니다.
4. 다운로드한 파일을 이 폴더의 `recipes.json`에 덮어쓰고 사이트를 재배포하면 새 방문자에게 데이터가 보입니다.
5. 배너/요리 이미지는 `assets/`에 저장하고 관리 화면에 상대 경로를 입력하는 것을 추천합니다. 브라우저에서 직접 올린 이미지는 데이터 URL로 저장되어 저장 용량 제한이 있습니다.

## 호스팅

GitHub에 이 폴더 내용을 업로드한 뒤 Vercel에서 GitHub 저장소를 연결하고 Framework Preset을 `Other`로 설정합니다. 빌드 명령은 비우고 Output Directory는 프로젝트 루트(`.`)를 사용합니다. 또는 Netlify에 폴더를 업로드해 정적 사이트로 배포할 수 있습니다.

## 주의

- 기본 요리 10개는 **실제 세레스 레시피가 아닌 예시**입니다. 반드시 실제 데이터로 교체하세요.
- 브라우저 저장(localStorage)은 계정/기기 간 동기화되지 않습니다. 방문자가 수정한 내용은 다른 사용자에게 자동 공개되지 않습니다.
- 관리자 버튼에는 인증이 없습니다. 방문자도 자신의 브라우저에서 데이터를 바꿀 수 있지만 다른 사용자나 배포된 원본에는 영향을 주지 않습니다. 중앙 관리 및 로그인은 추후 데이터베이스와 인증을 추가해야 합니다.
- 사이트 설정(배너/제목/색상)은 브라우저에만 저장됩니다. 전체 공개용으로 고정하려면 `app.js`의 기본 설정과 `style.css`를 수정하고 배포하세요.
- 이미지 및 게임 자료를 공개할 때 사용 권한을 확인하세요.


## 글씨체 적용
사용자가 보유한 `Griun_Cocochoitoon-Rg.ttf` 파일을 `assets` 폴더에 직접 넣어 주세요.
폰트 파일은 이 압축파일에 포함하지 않았습니다.
상단 SERES 로고, 메인 SERES COOKBOOK 로고, 하단 SERES COOKBOOK 로고는 기존 글씨체를 유지합니다.


## 글꼴 설정
사용자가 보유한 `Cafe24DongdongRegular.ttf` 파일을 `seres-cookbook/assets/` 폴더에 넣으세요. 사이트 전체의 한글과 상단 작은 '세레스 요리 도감' 글씨에 적용됩니다. 영문 SERES/COOKBOOK 로고는 기존 글꼴을 유지합니다. 폰트 파일은 배포 ZIP에 포함되지 않습니다.


글꼴 변경: 관리 → 사이트 설정 → 사이트 글꼴에서 선택하거나 TTF/OTF/WOFF/WOFF2를 업로드한 후 설정 저장. 직접 업로드한 글꼴은 브라우저 IndexedDB에 저장되어 같은 브라우저에서 유지되며 다른 사용자/기기에는 자동 배포되지 않습니다. SERES 영문 로고 글꼴은 유지됩니다.


## 이번 수정: 티어별 색상과 제작자 글꼴
1~10티어에 각각 다른 색상이 적용됩니다. 제작자 문구는 사이트 글꼴 설정을 따릅니다.
기존 사이트의 `assets` 폴더에 있는 폰트 파일(.ttf)은 그대로 유지해 주세요.
이번 배포 ZIP에는 폰트 파일이 포함되지 않으므로, 기존 폴더를 삭제하지 말고 새 파일을 덮어쓰세요.


추가 수정: 관리자에서 효과 카테고리 이름/아이콘/자동 분류 키워드를 관리하고 요리별 카테고리를 선택할 수 있습니다. 이미지 업로드는 PNG/JPG/WEBP/GIF를 읽어 PNG로 정규화하고 미리보기를 제공합니다. 카테고리 설정은 현재 브라우저에만 저장됩니다.


요리 이미지 106개는 assets/recipes/에 한글 파일명으로 포함됩니다. 기존 브라우저에 저장된 빈 이미지 또는 Base64 이미지는 해당 요리의 파일 경로로 표시합니다. 기존 요리 수정 내용은 유지합니다. JSON 내보내기를 하면 이미지 경로가 포함됩니다.


업데이트: 창원 단감 둥근체 파일 내장, 최초 실행 시 글꼴 설정 자동 적용. 요리 이미지 106개는 assets/recipes 에 포함되어 있으며 재업로드할 필요가 없습니다. 관리자에서 같은 이름의 파일을 선택하면 이미지 경로만 연결합니다. 새 이미지는 정적 배포 시 assets/recipes에 넣고 경로를 지정하세요.
